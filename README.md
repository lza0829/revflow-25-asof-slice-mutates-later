# 07-revflow（冲流台）

冲流台 — 正向与冲正流水净额归并：正向装载 → 冲正关联入账 → 净额归并落余额 → 未平/超额隔离 → 流水净额与余额互证。

**不是** 多源 Feed 归并，**不是** 作业依赖编排，**不是** CDC 变更流，**不是** 质检签发，**不是** 数仓分层建设，**不是** 交班过户。  
**也不是** 收银/退款 CRUD 后台、电商订单、报表 CSV 看板——主链是**流水管道与净额状态**，不是业务单据编辑台。

## 启动

```bash
# 后端
cd backend
pip install -r requirements.txt
set DATA_DIR=%CD%\data
set FIXTURES_DIR=%CD%\..\fixtures
uvicorn app.main:app --host 127.0.0.1 --port 10700

# 前端
cd frontend
npm install
npm run dev
```

## 主链

账户登记 → 装载正向流水 → 装载冲正并关联原单 → 跑净额归并（已配平落余额，未平/超额进隔离）→ 互证报告核对「流水净额 vs 账户余额」→ as-of 余额切片按时点物化各账户净额

## as-of 余额切片

净额互证页可指定截止入账时刻 T 生成切片：只计入 `booked_at ≤ T` 且首次归并时刻 `settled_at ≤ T` 的已归并流水（正向 − 同类冲正），逐账户物化落库。

- **落库形态**（二选一）：切片头 `asof_slices` + 不可变按账户明细快照 `asof_slice_lines`；触发器禁改禁删，新切片一律新 id。
- **失败闭**（二选一）：切片头与全部账户明细同事务提交，任一步失败整体回滚，不留半套。
- T 之后的归并/撤销只改写「当前余额」；查看切片时当前余额仅并排对比（差异 = 当前余额 − 切片净额），不回写切片。

接口：`POST /api/asof-slices?cutoff_at=<T>` 生成；`GET /api/asof-slices` 列表；`GET /api/asof-slices/{id}` 明细（含并排差异）。

## 界面约定

页面文案全部中文；入口：总览 / 账户 / 正向流水 / 冲正流水 / 归并台 / 未平隔离 / 净额互证。  
视觉：**左轨编号导航 + 右侧账册横线工作面**（Literata / JetBrains Mono，靛蓝强调）；**不是**交班台那种顶栏品牌+横向流程条。
